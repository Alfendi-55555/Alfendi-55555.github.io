# PLAYLOG

## 1. 목적

PLAYLOG는 제가 플레이한 게임을 게임별로 정리해 두는 개인 게임 블로그입니다.
플레이하며 느낀 점과 기억하고 싶은 장면에 대한 기록, 좋아하는 게임 음악, 관심 있는 게임의 공식 소식, 소통할 수 있는 창구를 한곳에 모았습니다.

**이런 분을 위한 사이트입니다**
- 특정 게임을 좋아해서 이야기를 나누고 싶은 분
- 다음에 어떤 게임을 해 볼지 고민 중인 분
- 내가 모르는 게임 음악을 찾아 듣고 싶거나 음악 추천을 받고 싶은 분

**사이트에서 볼 수 있는 것**

| 메뉴 | 내용 |
|---|---|
| 라이브러리 | 플레이한 게임과 한줄 리뷰. 게임 케이스를 열고 카트리지를 꽂으면 그 게임의 기록으로 들어갑니다 |
| 기록 | 게임별 플레이 기록. 게임마다 그 게임에 맞춘 테마로 보입니다 |
| 음악 | 날마다 바뀌는 오늘의 게임 음악과 추천곡 |
| 소식 | 라이브러리 게임의 공식 소식 (닌텐도 코리아 · Steam) |
| 소개 | 저에 대한 소개와 PLAYLOG의 기록에 대한 집계 정보 제공 |
| 방명록 | 궁금한 점이나 하고 싶은 이야기를 남기는 곳 |

**만든 이유**
어린 시절에는 한 게임을 오랫동안 여러 번 플레이하며 이야기와 음악까지 세세하게 기억했지만, 점차 플레이한 게임이 쌓여가면서 즐거웠던 순간과 게임 플레이 당시의 감상이 가물가물해지는 점이 아쉬웠습니다.
그래서 플레이한 게임과 그때의 감상을 게임별로 모아 두고, 더 나아가 같은 게임을 좋아하는 사람들과 공유하고 나눌 수 있는 공간을 만들었습니다.

**주요 기능**
- 게임별 전용 테마 10종 — 설정에서 끌 수 있습니다
- 밝은 화면 / 어두운 화면 / 시스템 설정 따르기
- 라이브러리 케이스에 게임 정보(출시일 · 장르 · 플랫폼) · 한줄 리뷰 · 추천곡 바로가기
- 기록이 8편 이상인 게임은 게임 화면에서 찾기 · 태그 거르기
- 방명록: 실시간 작성 · 수정 · 삭제, 답글, 스팸 방지
- 게임 소식: 하루 두 번 자동 수집

## 3. 실행 · 수정 방법

### 내 컴퓨터에서 실행하기
Python 3만 있으면 됩니다(추가 설치 없음).

```bash
python scripts/build.py
python -m http.server -d _site
```

브라우저에서 http://localhost:8000 을 엽니다.
- 게임 소식을 인터넷에서 모으지 않고 빨리 확인하려면 `NEWS_OFFLINE=1 python scripts/build.py`
- `index.html`을 더블클릭해서 열면 데이터를 불러오지 못합니다(브라우저 보안 정책). 꼭 위처럼 서버로 엽니다.

### 기록 · 게임 고치기 — 에디터
저장소 폴더의 **`글쓰기.bat`** 을 더블클릭하면 브라우저에 에디터가 열립니다(이 컴퓨터에서만 씁니다).

- **기록 쓰기**: 일반 블로그처럼 쓰면 오른쪽에 실제 사이트와 같은 모양(그 게임의 테마까지)으로 미리 보입니다. 사진 · 캡션 · 대체텍스트 · YouTube · 스포일러를 넣고, 예전 기록을 불러와 고치거나 지울 수 있습니다.
- **게임 관리**: 라이브러리 게임의 이름 · 출시일 · 장르 · 플랫폼 · 테마 · 게임 아트를 더하고 고칩니다. 케이스 모양으로 미리 보입니다.
- **사이트에 올리기**: 바뀐 기록과 게임 정보를 GitHub에 올립니다. 1~2분 뒤 사이트에 반영됩니다.

### 고치는 곳

| 하고 싶은 일 | 고칠 곳 |
|---|---|
| 기록 쓰기 · 고치기 | `글쓰기.bat` 을 더블클릭하면 열리는 글쓰기 에디터(이 컴퓨터에서만). 파일로 직접 쓰는 방법은 [WRITING.md](WRITING.md) |
| 게임 추가 · 고치기 | 같은 에디터의 「게임 관리」 (또는 `content/games.json` 직접) |
| 소개 페이지 문장 | `content/profile.json` |
| 오늘의 게임 음악 · 한줄 리뷰 | 구글 시트 (저장소 변수 `MUSICLIST_CSV`, `REVIEWS_CSV`) |
| 방명록 답글 · 숨기기 | 구글 시트의 `방명록` 탭 (Apps Script 웹앱 `GUESTBOOK_API`) |
| 화면 디자인 | `css/` (게임별 테마는 `css/skins/`) |
| 화면 동작 | `js/` (화면마다 파일 하나) |

시트 형식, 방명록 서버 설정, 게임 소식이 모이는 방식, 테마 추가 방법 같은 자세한 내용은 [GUIDE.md](GUIDE.md)에 정리했습니다.

### 배포
`main` 브랜치에 push하면 GitHub Actions가 `scripts/build.py`로 사이트를 만들어 GitHub Pages에 올립니다.
하루 두 번(한국시간 오전 · 오후 8시 17분쯤) 자동으로 다시 빌드해서 시트의 음악 · 리뷰와 게임 소식을 새로 반영합니다.
시트를 고친 뒤 바로 반영하려면 Actions → Build & Deploy → Run workflow를 누릅니다.

## 4. 현재 상태

### 진행 상황
모든 메뉴(홈 · 라이브러리 · 기록 · 음악 · 소식 · 소개 · 방명록 · 설정)가 작동합니다.
지금 라이브러리 게임 45개, 기록 7편, 한줄 리뷰 9개, 추천곡 20곡이 있습니다.

**준비 중**
- 기록은 5개 게임에만 있습니다. 나머지 게임은 한줄 리뷰를 먼저 채우고, 기록은 플레이하면서 추가하고 있습니다. 기록이 없는 게임은 케이스에 「아직 기록이 없어요」로 표시됩니다.

### 점검과 수정 결과

| 점검한 것 | 결과 | 수정 |
|---|---|---|
| 휴대폰 폭(375px)에서 가로 넘침 | 모든 메뉴 화면 · 게임 화면 · 글 읽기 화면을 하나씩 열어 확인. 넘침 없음 | — |
| 키보드(Tab) 초점 | 글 카드 · 카트리지 · 테마 화면 버튼의 초점 표시가 약하거나 없었음 | 테마마다 잘 보이는 색으로 3px 초점 테두리 |
| 이미지 대체텍스트 | 본문 사진에 캡션이 없으면 대체텍스트가 비어 있었음 | 사진마다 대체텍스트를 적을 수 있게 하고, 빠뜨리면 빌드할 때 알림. 글 표지 · 프로필 사진에도 대체텍스트 |
| 예시 문구 · 샘플 | 샘플 글 7편, 소개 페이지의 샘플 문장이 남아 있었음 | 샘플 글 삭제, 소개 페이지를 실제 내용으로 교체 |
| 링크 · 이미지 | 실제 사이트의 모든 메뉴 화면과 게임 화면에서 빈 링크 · 깨진 이미지가 없는지 확인. 문제 없음 | — |
| 읽기 편한 화면 | 한글 제목 · 게임 이름이 단어 중간에서 끊겼고, 게임 이름이 영문이라 어색했음 | 띄어쓰기 단위 줄바꿈, 게임 이름을 한국 공식 표기로 통일 |

### 사용한 자료
- **글꼴**: Google Fonts — Noto Sans KR, Noto Serif KR, IBM Plex Sans KR, IBM Plex Mono, Space Grotesk, Archivo, Bitter, Titan One, Black Han Sans, Jua, Fredoka, Do Hyeon, Cinzel, Bagel Fat One, Marcellus, Dongle, Baloo 2 (SIL Open Font License), Luckiest Guy (Apache License 2.0)
- **게임 테마 분위기 참고**: 각 게임의 공식 사이트(한국 닌텐도, 일본 닌텐도, SEGA 아시아 등). 색과 분위기, 디자인 포인트를 구상하는데 참고하였으며, 공식 이미지 · 로고는 사용하지 않았습니다. 테마의 무늬와 그림은 모두 별도로 생성한 SVG입니다.
- **게임 정보**: 출시일 · 장르 · 플랫폼은 한국 닌텐도 · 각 게임 공식 페이지와 게임 뉴스 · 백과 자료로 확인했습니다
- **게임 소식**: 닌텐도 코리아 뉴스, Steam 공식 공지 — 제목 · 요약 · 링크만 보여 주고 원문으로 연결합니다
- **음악 썸네일**: 각 곡의 듣기 링크(YouTube · Spotify 등)가 제공하는 앨범 커버. 이미지에 대한 모든 권리는 각 게임의 개발사 · 배급사에 있으며, 저는 이에 대해 어떠한 권리도 주장하지 않습니다. 권리자의 요청이 있으면 바로 삭제 및 수정합니다.
- **게임 아트 · 글 사진**: 각 게임의 공식 스토어 이미지와 직접 찍은 게임 스크린샷을 함께 사용했습니다. 이미지와 게임 화면에 대한 모든 권리는 각 게임의 개발사 · 배급사에 있으며, 저는 이에 대해 어떠한 권리도 주장하지 않습니다. 이 사이트는 비영리 개인 기록으로, 이미지는 게임을 소개하고 감상을 남기기 위해서만 사용합니다. 권리자의 요청이 있으면 바로 삭제 및 수정합니다.
- **서비스**: GitHub Pages · GitHub Actions(배포), Google Sheets · Apps Script(음악 · 리뷰 · 방명록)
